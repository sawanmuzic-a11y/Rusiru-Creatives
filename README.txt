RUSIRU CREATIVES WEBSITE
========================

FILES
- index.html  : Complete website structure and content
- style.css   : Responsive premium dark theme and animations
- script.js   : Services, portfolio filters, lightbox, mobile menu and WhatsApp links

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview in Chrome.

EDIT PORTFOLIO IMAGES
Open script.js and find the `projects` declaration.
Each portfolio item is currently an explicitly labelled placeholder, not a claimed completed client project.
To use your own image, add an `image` property to a project object, for example:
  image: "images/my-social-post.jpg"
Then create an `images` folder beside index.html and put your image there.
The project preview/lightbox will use the image automatically.
Keep your image files inside the website folder.

CUSTOMIZE TEXT
- Service names and bilingual sub-services are in `serviceData` in script.js.
- Portfolio category names and placeholder entries are in `portfolioCategories`.
- Website text and section content are in index.html.
- Colors, spacing and responsive layout are in style.css.

NOTES
